Application documentation

From product intent to reusable test intelligence.

TestPilot AI converts pasted or uploaded requirements into structured manual and automated test cases. Repository-owned Markdown files define each agent's readable policy, while the FastAPI execution layer enforces routing, validation, conversion, storage, and the web experience.

How the application works

SpecForge routes each request through focused agents in a governed sequence.

01 · GROUND

Input & Business Rules

Extract requirements, normalize explicit rules, and preserve BR traceability.

02 · RECALL

Knowledge Agent

Returns an exact validated match before any new Copilot request.

03 · DESIGN

SpecForge & Specialists

Generate manual and automation tests, synthetic data, and independent validation.

04 · OPERATE

Lifecycle Agents

Summarize execution, draft defects, and calculate transparent quality metrics.

Standardized test generation

Every requirement uses the same governed format and quality basis so test suites remain consistent, comparable, exportable, and easy to use across teams.

Generation basis

  • Critical business path and highest product risks
  • Important positive, negative, boundary, authorization, accessibility, and failure behavior where relevant
  • Four to five concise scenarios with at least two automation and two genuinely manual cases
  • Synthetic test data and explicit acceptance-criteria traceability

Standard case structure

  • Stable ID, title, and objective
  • Category, priority, and manual/automation classification
  • Case-specific feasibility reason and preconditions
  • Actions with observable expected results
  • Test data, tags, acceptance-criteria mappings, and optional SpecFlow Gherkin

Application use cases

Common ways quality teams can use the pipeline.

Business-rule grounding

Combine a BRD, story, or acceptance criteria with explicit BR rules and review case-level traceability.

Document-to-tests

Upload a requirements document, spreadsheet, PDF, or UI image and convert its extracted content into a structured suite.

Knowledge reuse

Return a previously validated exact-match suite without another premium Copilot request.

Test data preparation

Create privacy-safe synthetic values aligned with each generated case.

Execution and defects

Record approved run results and create human-review-required defect drafts for failed cases.

Quality metrics

Calculate manual and automation proportions, pass rate, defect totals, and defect density from reviewed evidence.

Supported inputs

Direct text

User stories, feature descriptions, business rules, and acceptance criteria up to 30,000 characters.

Business documents

Word `.docx`, text PDF, Excel `.xlsx`, Apple Pages `.pages`, and Apple Numbers `.numbers`. iWork packages are read from their local Quick Look preview or legacy XML; binary-only files must be exported from the Mac as PDF or XLSX.

Images

PNG and JPEG through local Tesseract OCR. Files are limited to 15 MB, and oversized images are rejected safely.

Outputs and future reference

Each suite includes categorized test cases, priority, manual/automation classification, feasibility rationale, preconditions, steps, expected results, test data, tags, and acceptance-criteria mappings.

Manual test cases

Numbered actions with observable expected results for review and execution.

BDD scenarios

Copy-ready SpecFlow Gherkin using Scenario or Scenario Outline where appropriate.

Validated memory

Only newly generated suites without validation errors are written to the local SQLite store. Cached results are revalidated when retrieved.

Integrations and API

POST /api/agent/runGround rules, recall knowledge, generate, and validate a suite.
POST /api/generate/documentExtract a document and run the governed pipeline.
POST /api/test-dataFill missing values with case-aligned synthetic data.
POST /api/executionValidate and summarize supplied execution results.
POST /api/defectsCreate review-required defect drafts from failed tests.
POST /api/metricsCalculate coverage, execution, and defect metrics.
GET /api/agentsList functional agents, responsibilities, runtimes, and capabilities.
POST /api/context-converter/{format}Convert an approved suite to Xray CSV, XLSX, or JSON.
POST /api/jira/publishAttach selected tests to Jira Cloud after explicit user approval.
GET /docsInteractive OpenAPI documentation.
